# Lugaire — Fashion Storefront and Editorial Site

A Next.js and React storefront concept for Lugaire. The site pairs an editorial fashion presentation with product and brand-information pages, account screens, and responsive navigation.

**Live site:** [lugaire-design-system.vercel.app](https://lugaire-design-system.vercel.app)

## Stack

- Next.js and React
- TypeScript
- Tailwind CSS
- Motion-based interactions
- Base UI and Lucide icons

## Run locally

Requirements: Node.js and pnpm.

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

The repository is linked to a v0 project for iterative UI work. The live site is a front-end concept; confirm backend, payment, inventory, and account integrations before treating any commerce flow as operational.
